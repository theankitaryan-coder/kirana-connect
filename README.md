# Kirana Connect

Online ordering website for **Bharti Retail Chain**, a neighbourhood retail store.
Built as the client project for Agile Software Development (CBCA251) – tracked in Jira project **KC**.

**Live site:** https://theankitaryan-coder.github.io/kirana-connect/

## Features (Sprint 1)
- Home header with shop name, address, timings and a Call button (KC-7)
- Product catalogue with name, Hindi name, unit and price (KC-8)
- Filter products by category (KC-9)
- Hosted free on GitHub Pages (KC-6)

## Features (Sprint 2)
- Search products by English or Hindi name (KC-10)
- Add to cart, change quantity, remove items (KC-11)
- Cart total, saved on the device after refresh (KC-12)
- Checkout form: name, 10-digit mobile, delivery or pickup, address (KC-13)

## Features (Sprint 3)
- Place order: order ID + one-tap WhatsApp message to the shop with items, total and customer details (KC-14)
- Order Book page for shop staff (`orders.html`): opening the link in the WhatsApp message adds the order, no duplicates (KC-15)
- Today's orders with counts, value and status filter (KC-16)
- Fix: delivery/pickup radio buttons aligned with their labels (KC-33)

## Run locally
Open `index.html` in any browser – no build step needed.

Store details and products are in `data/store.js` and `data/products.js` (sample data until the client shares the final list).
